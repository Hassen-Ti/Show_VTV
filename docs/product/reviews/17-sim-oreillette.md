## Verdict simulation

L'oreillette n'est pas le centre — c'est un **accent**, pas le pilier.

| Pilier engagement | Poids révisé |
|-------------------|--------------|
| Tension visible (SYSLOAD) | 35% |
| Drift stance (voir opinions bouger) | 30% |
| Voix / embodiment | 25% |
| Oreillette | 10% |

| Changement | Décision |
|------------|----------|
| Renommer produit « Oreillette TV » | ❌ |
| Renforcer feedback paquet lu | ✅ P0 |
| Modérateur cite pseudo si fourni | **P1 NEW** |
| Priorité oreillette quand SYSLOAD > 0.6 | **P2** |

**Pas de changement produit #1** — priorisation interne ajustée.
