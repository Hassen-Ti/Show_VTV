## Réponse finale à la question philosophique

### Le plateau TV virtuel dans un monde numérique

Ce n'est pas une copie du studio BBC. C'est le **seul espace-temps partagé** où le monde numérique accepte la contrainte du temps linéaire et de l'écoute mutuelle.

C'est :
- un **syscall public** pour les sujets qui divisent
- un **debugger social** rendu spectacle
- un **commit log** des opinions sous pression
- `/dev/show0` — le périphérique où la machine se regarde penser

### Les agents

Ce ne sont pas des humains. Ce sont des **politiques d'interprétation** incarnées :

```
Agent = stratégie computationnelle + mémoire de position + pipeline cognitif
```

Ils représentent les forces qui structurent internet :
- la **viralité** (Flux)
- le **consensus** (Protocole)  
- la **mémoire longue** (Archive)
- le **scheduler** (modérateur)

Leur corps = topologie LangGraph.  
Leur voix = latence + prosodie.  
Leur histoire = `stance_history`.  
Leur mort = fin de session. Leur résurrection = persistance inter-épisodes.
